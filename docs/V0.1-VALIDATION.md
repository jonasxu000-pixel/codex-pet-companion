## 0.1.2 自动启动修复（2026-09-16 晚）

- 原问题现场：小助手不存在，上午最后记录是正常退出；晚间 Codex 已重新运行，旧 Run 值仍在 Codex 内可见，但没有晚间小助手启动记录。
- 隔离对照：同一 Windows 用户、同一 LocalAppData 日志路径，Codex 工具进程打开文件的最终路径位于 Codex 应用 LocalCache，计划任务进程的最终路径位于真实用户 LocalAppData；自建注册表探针仅在 Codex 工具进程可见。临时探针和诊断任务测试后已移除。
- Release 编译通过（零警告），200 项测试通过。新增 5 项覆盖无 Codex 时不启动、正常恢复、主动退出抑制、重新打开 Codex 后恢复、手动恢复及损坏暂停文件。
- 安装脚本成功注册当前用户的交互式计划任务，并由计划任务服务实际启动 0.1.2。计划任务进程日志记录 scheduled recovery 与 Codex detected，额度条可见，真实鼠标悬停展开成功。
- 恢复实测：发送 WM_CLOSE 关闭小助手，不执行 EXE 或手动启动任务；约 12.9 秒后一分钟周期自动启动新进程，任务 LastRunTime 同步更新，保持单实例。整个过程未关闭 Codex。
- 任务配置核对：登录、解锁和每分钟触发；电池可运行；不要求网络或管理员权限；不保存密码；无限运行时长；禁用唤醒电脑。

仍未验证：实际整机重启/注销/解锁触发；主动退出后重新打开真实 Codex 的端到端流程（规则已单元测试）；多显示器与真实断网恢复。此前手动执行 --startup 的记录仅证明命令有效，不能视为 Windows 自动登录验收。
